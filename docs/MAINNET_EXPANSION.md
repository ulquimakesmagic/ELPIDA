# V2.3 expansion checks

26 November 2026. Scope: Arbitrum One, HyperEVM, Elysium (Kinetiq), and Arc. The public RPCs returned the expected chain IDs and bytecode at each chain's [published Uniswap v4 PoolManager](https://developers.uniswap.org/docs/protocols/v4/deployments). The planned Elpida Treasury address had no contract code on any of the four chains.

Use the [mainnet deployment runbook](V2_MAINNET_DEPLOY.md) for the Arbitrum preflight. A plan in Git leaves the chain hidden. Before publishing a `ready` record, verify the Safe configuration, launch a token and complete a buy and sell, confirm index catch-up and the trader payout path, and configure the chain's server RPC. Each mainnet transaction requires Malik's approval.

Arbitrum's live read-only preflight passed every check except the missing treasury Safe. A local fork using a temporary Safe and test wallets passed preflight, contract deployment and wiring verification, a native token launch, and the guardian stop. The launchpad fork rehearsal does not include a buy/sell or an airdrop conversion. Its deployment record was temporary.

The Arbitrum plan uses a provisional **0.003 ETH** deployer balance floor and a gas estimate carried over from the Ethereum V2.3 plan. Recheck with current fees and a rehearsal before funding. Budget Safe setup, keeper funding, and the smoke test separately. HyperEVM funding needs a big-block estimate if deployment uses big blocks. Elysium and Arc remain at prerequisite review.
